# CampusConnect

CampusConnect is a responsive student portal concept that brings campus events, academic resources, services, and student announcements into one place.

## Run locally

Open `index.html` directly in a browser, or serve the folder with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included interactions

- Responsive navigation menu
- Search filtering for courses, events, resources, and services
- Event category tabs
- Notification panel
- Mobile-friendly layout
- Accessible labels and semantic content
